# The Readout-Governance Intervention Framework (RGIF)
## Treating the readout-to-policy lock, not merely the fear — a derived treatment *hypothesis*

**Companion document S11 to *Why We Phobia?* v14 · 2026-09-02 · Dr tier ทั้งฉบับ**

## 1. การเปลี่ยนแกนของการรักษา

หลักการรักษาแบบเดิมโดยนัยคือ $\text{กลัว} \to \text{ลดความกลัว}$ กรอบนี้แทนด้วยลำดับที่
Genesis บังคับ (ห้ามกระโดดเข้า belief ก่อน):

> **ตรวจ state จริง → เปิด record channel → แก้ translation → สร้าง readout ใหม่ →
> เปิด alternative policy → ให้ระบบเดินจนเกิด new retained state**

และหน่วยของการรักษาเปลี่ยน:

> **หน่วยการรักษาไม่ใช่ fear reduction และไม่ใช่ exposure-minute แต่คือ
> "successful information-bearing continuation" — เหตุการณ์ที่เดินถึงจุดจบที่ดี
> ขณะที่ phobic readout ยังทำงานอยู่ และระบบยังเลือก policy อื่นได้ก่อน premature
> termination** — สั้นที่สุด: *treat the readout-to-policy lock, not merely the fear*

RRHM ให้ครึ่งแรก (เมื่อไรระบบคิดว่า recover ไม่ทัน — the horizon) Genesis ให้ครึ่งหลัง
(readout กลายเป็น action command ได้อย่างไร และทำให้กลับมา interruptible ตรงไหน)

## 2. เจ็ดปฏิบัติการ (the 7 operations)

| # | ปฏิบัติการ | เนื้อหา | เทียบ practice เดิม / อะไรไม่มาตรฐาน |
|---|---|---|---|
| 1 | **Ground-truth gate** | แยก actual hazard / physiological vulnerability ออกจาก readout error **ก่อนเสมอ** — dysphagia ที่ยังมีจริงไม่ใช่ phobia; vasovagal ที่ eRRH^C สั้นจริงต้องขยาย recoverability จริงก่อน | ตรง medical mimic gate ของ RRHM; ไม่มาตรฐานตรงที่เป็น *เกตบังคับลำดับ* ไม่ใช่แค่ differential |
| 2 | **Readout decomposition** | วัดแยก lane: verbal fear · physiology · action tendency · recoverability estimate · actual termination — ห้ามรวมเป็น scalar เดียว | ต่างจาก SUDS-based practice ที่ใช้ fear rating เป็นแกนเดียว |
| 3 | **Tape audit** | ไล่ retained history: record ไหนคือ harm จริง (H), benign completion (C), censored escape (E) — และระบบกำลังอ่าน E≈H หรือไม่ (Eq. lesion ใน v13) | คือ T1 (reattribution) ที่มีบัญชีรองรับ |
| 4 | **Causal repair** | ถ้า recoverability จริงต่ำ → เพิ่มมันก่อน (เช่น applied tension ยก g ใน ADM = เลื่อนหน้าผา P3) แล้วค่อย sample boundary — ไม่พาคนไปชน boundary ที่ร่างกายช่วยตัวเองไม่ได้ | Evidence เข้าทิศ: review รักษา BII พบ exposure + applied tension มีประโยชน์ โดย tension ช่วยเรื่อง fainting (Ayala 2009, PMID 19464700, abstract) |
| 5 | **Completion engineering** | ออกแบบเหตุการณ์ให้ถึง benign completion จริง (ไม่หลอก ไม่ใช้ reassurance ล้วน) — โดสคือจำนวน C ตาม n* (Eq. v13) ไม่ใช่นาทีที่ทน | เข้าทิศ inhibitory-learning แต่คมกว่า: completion count > exposure time; เคส choking-ARFID 8 ปีรักษาได้ด้วย multimodal + inhibitory-learning-informed exposure (Finn 2026, PMID 42243909, J Eat Disord, abstract) |
| 6 | **Meta-readout + interruptibility** | ฝึก "readout ≠ command": สร้าง readout-of-readout ("ฉันมี readout ว่าระบบกำลังพัง" ≠ "ต้องเข้าสู่ response นี้") + คง alternative-policy set {tension, posture, stop, continue-small, signal-clinician} ไว้จนก่อน commitment point — ไม่ใช่ denial ว่าอาการไม่จริง | ไม่มาตรฐาน; ใกล้ ACT/defusion แต่ derive จากคนละราก และให้ตัววัดใหม่ (ข้อ 4 ล่าง) |
| 7 | **Transport test** | ถอด therapist / context / safety cue / สภาวะร่างกาย ออกทีละตัว แล้วดูว่า readout ใหม่เดินทางข้าม context ไหม | คือ generalization testing ที่ทำเป็นระบบ + ตรง P10/บันได bandwidth |

## 3. เคสโหด 3 แบบ — จุดที่กรอบนี้ให้คำตอบต่างจาก cognitive approach

**เคส 1 — "รู้ว่าไม่สำลัก แต่กลืนไม่ได้" (post-organic, ไม่มี safe baseline):**
อย่าเริ่มที่ belief — เด็กพูด "รู้ว่าปลอดภัย" คือ R_verbal; R_action ยัง terminate swallow
สองอย่างไม่ต้องตรงกัน Tape audit จะพบร้อย record ที่เกือบทั้งหมดเป็น E (จบก่อนเห็นผล)
ถูกอ่านเป็น ≈H → การรักษา = completion engineering (tiny solid → chew → swallow →
recover → C₁, C₂, ...) + record reclassification หลังทุกครั้ง: ไม่ใช่สอนว่า "เห็นไหมไม่สำลัก"
แต่สอนว่า **R_danger ≠ S_danger — readout เกิดขึ้นได้โดยไม่ต้องกลายเป็น policy** —
ลึกกว่า cognitive restructuring เพราะระบบไม่ได้เรียนว่า "ฉันคิดผิด"

**เคส 2 — BII + เป็นลม + functional seizure:**
"exposure ให้สุด" อาจผิดตั้งแต่ต้น — ลำดับบังคับ: (1) ground truth: vasovagal จริง = eRRH^C
สั้นจริง → **เพิ่ม recoverability จริงก่อน** (applied tension = เพิ่ม g) แล้วจึง sample
boundary; (2) functional seizure **ห้ามยัดเข้า RRHM** — ประเมินตาม AAN Practice Guideline
2026 (Tolchin, Goldstein, Reuber et al., Neurology, PMID 41370742, abstract: semiology,
video-EEG เมื่อเหมาะสม, psychological interventions ช่วยลด episodes ได้); (3) หลังวินิจฉัย
แล้วจึงเสริม meta-readout + interruptibility: เป้าไม่ใช่ "ห้ามเป็น seizure" แต่คือ
**R⁽¹⁾ ⇏ single irreversible policy**

**เคส 3 — spider phobia ที่ belief ถูกหมดแล้วแต่ร่างกายหนีก่อนคิด (300 ms):**
defect ไม่อยู่ชั้น belief → ไม่มีอะไรให้ restructure — รักษาด้วย micro-continuations
ก่อน commitment point (เห็น spider ไกล → ร่างกายอ่าน "ออก" → ยังไม่ออก 2 วินาที →
alternative policy → recover → complete) เป้าคือเปลี่ยน P(escape|R_phobic)≈1 ให้ <1
**โดยไม่ต้องทำให้ R_phobic = 0** — คนไข้ไม่ต้อง "ไม่กลัว" จึงจะหาย

## 4. คำทำนายหัวชนกับ cognitive model (แปลก แต่คมและวัดได้)

> **ในผู้ป่วยบาง subset: behavioral governability ต้องเปลี่ยนก่อน phenomenal fear**
> — ลำดับที่ทำนาย: Fear 8/completion 1 → Fear 8/completion 5 → Fear 6/completion 20
> → Fear 3 · ถ้าพบว่าการ approach ได้ต้องรอ fear ลดก่อน*เสมอ* โมเดลนี้เสียแต้มหนัก

ตัววัดใหม่ที่กรอบนี้สร้าง (ทดลองได้จริง):
1. **Completion count เทียบ exposure-minutes** เป็นตัวทำนาย outcome (โยง n*, T2 ใน v13)
2. **Interruptibility window**: ระยะจาก first readout → committed episode — สมมุติฐาน:
   คนที่ดีขึ้นไม่ได้มี warning น้อยลง แต่หน้าต่างนี้ "ขัดจังหวะได้" มากขึ้น (วัดได้ใน
   functional seizures และ vasovagal prodrome)
3. **Fear-lag**: dissociation ระหว่าง governability curve กับ fear-rating curve
4. **Transport curve**: readout ใหม่รอดกี่ context หลังถอด cue ทีละตัว (โยง C16/C18/P10)

## 5. รั้ว

- Ground-truth gate มาก่อนเสมอ — โรคทางกายที่ยังไม่รักษา ไม่ใช่ phobia
- Functional seizures เดินตาม guideline เฉพาะทาง ไม่เดินตามเอกสารนี้
- ทุกเคสจริงอยู่ใต้ผู้เชี่ยวชาญ; เอกสารนี้คือกรอบสร้างสมมุติฐาน/ออกแบบการทดลอง
- Evidence ที่อ้าง: Odgers 2022 (36323055, verified เต็มรอบ v7) · Ayala 2009 (19464700,
  abstract) · Finn 2026 (42243909, abstract) · Tolchin 2026 AAN (41370742, abstract) —
  ทั้งหมด "เข้าทิศเดียวกัน" ไม่ใช่ "พิสูจน์กรอบนี้"
- Maker-checker: same-agent extraction จากบทวิเคราะห์ของ session ร่วมสาย — independent
  checker ยังค้างทั้ง corpus
