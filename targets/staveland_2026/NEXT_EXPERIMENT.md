# The experiment the current task cannot run — minimal Pac-Man modification

**Purpose:** separate *termination* from *engagement-preserving correction* while holding
threat, control count, and exits constant — the direct test of eRRH that the existing
dataset cannot provide (stated by us, up front).

## Design
Two actions, matched for salience, count, and motor cost:
- **Action A — termination:** escape → trial ends (as now).
- **Action B — engagement-preserving correction:** shield / pause / corrective retreat →
  threat neutralized for a bounded window, the trial CONTINUES, collecting resumes.
- **Programmed expiry D_j on Action B:** per trial, B remains available/effective for a
  known-or-cued remaining budget (long on some trials, near-exhausted on others). This
  manipulates estimated engagement-preserving recoverability (êRRH_C) with the physical
  ghost threat unchanged.

## Frozen predictions
- **P-S1 (behavioral, RRHM-specific):** same threat + same control count + same exits +
  different D_j ⇒ different defensive-transition time; transition tracks remaining D_j,
  not ghost kinematics alone.
- **P-S2 (neural):** shorter êRRH (low remaining D_j) ⇒ earlier shift of the
  cortico-limbic dynamics toward the pattern the paper associates with the
  approach→avoid transition.
- **P-S3 (dissociation):** at matched D_j, A-availability changes little — the horizon
  on the ENGAGEMENT-PRESERVING channel, not exit availability, carries the effect
  (mirrors our C-vs-D logic in prereg case C32).

## Kill criteria
Transition time insensitive to D_j at matched threat ⇒ the eRRH term does no work in this
paradigm — recorded as a FAIL against RRHM's central claim, not explained away.
